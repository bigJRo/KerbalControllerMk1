# ILI9341_t3 fonts (converted from sumotoy tFont)

These `.c` files are the KCMk1 display fonts converted from the original sumotoy
`tFont` format (in `../fonts/`) to **ILI9341_t3** format, for the wwatson4506
RA8876 GFX text engine used on the 7" TFT (hardware rev 2).

- Generated by `tfont_to_ili9341.py` (vendored here for reproducibility):
  ```
  python3 tfont_to_ili9341.py ../fonts ./
  ```
- The converter **round-trip verifies** every glyph: it decodes its own output
  with the ILI9341_t3 `drawFontChar` bit logic and asserts the bitmap matches the
  source pixel-for-pixel. Conversion aborts on any mismatch.
- Glyphs are emitted full-height and top-aligned (`height = font_height`,
  `yoffset = 0`, `cap_height = font_height`) so `origin_y = cursor_y` — preserving
  the old top-left cursor semantics of the sumotoy/RA8875 text helpers.
- `delta` (advance) = glyph width, matching the old `getFontStringWidth()` sum so
  text alignment math stays consistent.
- Special glyphs (Δ, °, µ, ¤, arrows/symbols 0x80–0x8d) are carried in a second
  index range (0x80–0xb5) with blank entries for unused codes.

`kcm_ili9341_font.h` supplies the `ILI9341_t3_font_t` type — it prefers the
installed library's definition (via `__has_include`) and falls back to the
canonical layout. See `../../../PORTING_7inch_TFT.md`.

## KcmTerm (monospace terminal font)

The `KcmTerm_*` fonts carry the glyph **bitmaps of Terminus Font 4.49** (SIL Open
Font License 1.1, Reserved Font Name "Terminus Font" — so this derived subset uses
a different name; see `OFL.txt`). They replace the old IBM VGA `TerminalFont` and an
earlier outline-rendered attempt: because Terminus ships as hand-designed **bitmaps**,
the glyphs are pixel-exact at every native size — no rasterisation, none of the
diagonal-stem distortion (e.g. `Y`) an outline font shows off its design grid.

Generated by `bdf_to_ili9341.py` (pure Python, no PIL) from the Terminus BDF sources
(`ter-uNNn.bdf`, from the Terminus Font 4.49 distribution):

```
python3 bdf_to_ili9341.py ./ KcmTerm \
  16=ter-u16n.bdf 20=ter-u20n.bdf 24=ter-u24n.bdf 28=ter-u28n.bdf 32=ter-u32n.bdf \
  36=2x18 40=2x20
```

- Native Terminus strikes (16/20/24/28/32) are used verbatim. A `N=2xM` token
  pixel-doubles the native `M` strike to an exact `N=2M` size (`40=2x20`, `36=2x18`)
  — artifact-free, for heading sizes Terminus has no native strike at.
- Each glyph is placed full-cell and top-aligned, `width == delta == cell_w` (true
  monospace, so dotted-leader columns align by character count). ASCII `0x20–0x7e`.
- Same **round-trip verification** as above: every glyph is decoded back with the
  ILI9341_t3 bit logic and asserted pixel-identical before emit.

The `ter-uNNn.bdf` sources are not vendored (they are large); fetch them from the
Terminus Font 4.49 distribution to regenerate.

Fonts: Roboto_Black_{12,16,20,24,28,32,36,40,48,72}, KcmTerm_{16,20,24,28,32,36,40}.
