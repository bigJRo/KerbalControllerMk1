# ILI9341_t3 fonts (converted from sumotoy tFont)

These `.c` files are the KCMk1 display fonts converted from the original sumotoy
`tFont` format (in `../fonts/`) to **ILI9341_t3** format, for the wwatson4506
RA8876 GFX text engine used on the 7" TFT (hardware rev 2).

- Generated by `tfont_to_ili9341.py` (vendored here for reproducibility):
  ```
  python3 tfont_to_ili9341.py ../fonts ./
  ```
- The converter **round-trip verifies** every glyph: it decodes its own output
  with the ILI9341_t3 `drawFontChar` bit logic and asserts the bitmap matches the
  source pixel-for-pixel. Conversion aborts on any mismatch.
- Glyphs are emitted full-height and top-aligned (`height = font_height`,
  `yoffset = 0`, `cap_height = font_height`) so `origin_y = cursor_y` — preserving
  the old top-left cursor semantics of the sumotoy/RA8875 text helpers.
- `delta` (advance) = glyph width, matching the old `getFontStringWidth()` sum so
  text alignment math stays consistent.
- Special glyphs (Δ, °, µ, ¤, arrows/symbols 0x80–0x8d) are carried in a second
  index range (0x80–0xb5) with blank entries for unused codes.

`kcm_ili9341_font.h` supplies the `ILI9341_t3_font_t` type — it prefers the
installed library's definition (via `__has_include`) and falls back to the
canonical layout. See `../../../PORTING_7inch_TFT.md`.

## Terminalia (monospace terminal font)

The `Terminalia_*` fonts are generated directly from `Terminalia-Regular.ttf`
(no sumotoy intermediate) by `ttf_to_ili9341.py`:

```
python3 ttf_to_ili9341.py Terminalia-Regular.ttf ./ Terminalia 16 20 24 28 32 36 40=2x20
```

A `N=2xM` token pixel-doubles the native `M` px strike to an exact `N=2M` px size
(`40=2x20`) — perfectly clean, since doubling is artifact-free, whereas rendering
the outline directly at an off-grid size like 40 distorts diagonal stems.

- **Terminalia** is a Terminus-faithful monospace terminal font under the SIL
  Open Font License 1.1 (`OFL.txt`). It replaces the old IBM VGA `TerminalFont`
  (which shipped only in 16/32); the OFL family renders crisply at any size, so
  boot/terminal screens can pick whatever size fits.
- Each glyph is rendered 1-bit via FreeType **monochrome hinting** (`fontmode="1"`)
  — antialias+threshold drifts diagonal stems (e.g. `Y`), monochrome keeps them
  symmetric. Full-cell, top-aligned, `width == delta == cell_w` for every glyph
  (true monospace, so dotted-leader columns align by character count). The native
  Terminus pixel sizes (16/20/24/28/32) reproduce cleanest. ASCII `0x20–0x7e` only.
- Same **round-trip verification** as above: every glyph is decoded back with the
  ILI9341_t3 bit logic and asserted pixel-identical before emit.

Fonts: Roboto_Black_{12,16,20,24,28,32,36,40,48,72}, Terminalia_{16,20,24,28,32,36,40}.
